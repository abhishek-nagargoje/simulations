# Guides

## Teacher

1. Open the site → **Teacher Login**. Sign in with your email and password.
2. **Dashboard** shows the applications, active access, recently closed and expired access.
3. **Create Access** → choose the application (HR Management or SAP ERP), a name,
   the shared username, a password (**Generate** for a strong one) and the
   duration (24 hours at most). The username must not be used by another open access.
4. Copy the password from the confirmation **now** — it is stored only as a hash.
5. Open the access → **Start Access**. It is active from now until **Expires At**.
6. Share the **access link** and the credentials (preferably separately).
   Students can also sign in from **Student Login** with the username and password alone.
7. While active: **Change credentials** signs everyone out; **Reset Workspace Data**
   (SAP ERP) restores the imported data set; **End Access** stops all use immediately.
8. Ended or expired access cannot be reopened — create a new one. SAP ERP data of
   ended access is kept.
9. **Organization** (SAP ERP): company-code names and open posting periods.

## Student

1. Open the access link, or the site → **Student Login**.
2. Enter the username and password from your teacher → **Sign In**. The application opens directly.
3. Keep the tab open; the page checks every few seconds that access is still valid.
   If the teacher changes the credentials you are asked to sign in again; when
   access ends or expires the application closes.
4. SAP ERP: postings are saved to the shared workspace of your access when you
   post or save. **Extras › Reload Data** shows changes made by others.
   HR Management: your work is kept in this browser for this access.
5. **Exit** (top right, or Log Off in SAP ERP) signs you out on this device.
